# История изменений Amotorg

## v3.0.0 — 21.11.2026

- Снова подключена DaData для поиска компаний по ИНН и банков по БИК, с единым защищённым серверным маршрутом `/api/lookup` и переменной `DADATA_TOKEN`.
- Серверные обработчики для Netlify, Cloudflare Pages и локального Eleventy.
- Приоритет автозаполнения: автоматический поиск после ввода полного ИНН/БИК; ручное редактирование любых полей, сохранение правок между поисками, явное принудительное обновление.
- Удобная структура формы: исполнитель → банк → заказчик → счёт/акт/договор → услуги → подписи.
- Договор: название, номер и дата; комментарий показывается и в счёте, и в акте.
- Исправлена верстка акта: длинные должности и ФИО не налезают друг на друга. Отдельная подпись заказчика.
- Данные руководителя из DaData могут подставляться в поля подписанта, но их необходимо проверять.
- Кнопка «Новый счёт» сохраняет постоянные реквизиты и обновляет номер счёта.
- Сохранена чистая печать A4 из отдельного документа без интерфейса сайта.
- JSON-черновики v1/v2 читаются в v3; новая версия хранит дополнительные поля.
- Обновлены тесты, примеры и документация развёртывания.
